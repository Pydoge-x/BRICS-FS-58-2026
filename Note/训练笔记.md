# Ubuntu 安装 Docker 及免账号镜像加速

## 一、前置检查

```bash
# 内核版本需 >= 3.10
uname -r
```

---

## 二、卸载旧版本(可选)

```bash
sudo apt-get remove -y docker docker-engine docker.io containerd runc
```

---

## 三、安装依赖

```bash
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg lsb-release
```

---

## 四、添加阿里云 Docker CE 软件源

> 此处使用阿里云镜像站安装 Docker，不需要登录阿里云账号。

```bash
sudo install -m 0755 -d /etc/apt/keyrings

curl -fsSL https://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | \
  sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

sudo chmod a+r /etc/apt/keyrings/docker.gpg

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://mirrors.aliyun.com/docker-ce/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
```

---

## 五、安装 Docker

```bash
sudo apt-get install -y docker-ce docker-ce-cli containerd.io \
  docker-buildx-plugin docker-compose-plugin
```

---

## 六、启动并设置开机自启

```bash
sudo systemctl enable --now docker
```

---

## 七、配置免账号镜像加速器

以下加速源无需登录，可直接使用。建议配置多个，避免单点故障。

```bash
sudo mkdir -p /etc/docker

sudo tee /etc/docker/daemon.json > /dev/null <<'EOF'
{
  "registry-mirrors": [
    "https://docker.xuanyuan.me",
    "https://docker.1ms.run",
    "https://hub.rat.dev",
    "https://docker.m.daocloud.io"
  ]
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker
```

> 如果仍想使用阿里云加速器，可登录阿里云容器镜像服务控制台，获取专属地址后替换上面的数组内容。

---

## 八、验证

```bash
# 查看 Docker 版本
docker version

# 查看镜像加速器是否生效
docker info | grep -A 5 "Registry Mirrors"

# 拉取并运行测试镜像
docker pull hello-world
docker run --rm hello-world
```

---

## 九、免 sudo 使用 Docker（可选）

```bash
sudo usermod -aG docker $USER
newgrp docker
```

或重新登录终端后生效。

---

## 十、常用命令


| 操作              | 命令                     |
| ------------------- | -------------------------- |
| 查看镜像          | `docker images`          |
| 查看运行容器      | `docker ps`              |
| 查看所有容器      | `docker ps -a`           |
| 停止容器          | `docker stop <容器ID>`   |
| 删除容器          | `docker rm <容器ID>`     |
| 删除镜像          | `docker rmi <镜像ID>`    |
| 查看 Compose 版本 | `docker compose version` |
| 查看磁盘占用      | `docker system df`       |
| 清理无用资源      | `docker system prune -a` |

---

## 十一、注意事项

1. 第三方加速源可能随时失效，如拉取失败可更换其他源。
2. 公共加速源仅建议用于拉取公开镜像，请勿传输私有或敏感镜像。
3. 修改 `/etc/docker/daemon.json` 时注意 JSON 格式，避免多余逗号导致 Docker 启动失败。
4. 修改配置后必须执行：

```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
```

# Ubuntu 虚拟机 NAT 模式 SSH 连接指南

## 一、NAT 模式说明

NAT 模式下：

- 虚拟机可以访问外网。
- 宿主机不能直接通过虚拟机 IP 访问虚拟机。
- 需要在虚拟机软件中配置 **端口转发**，将宿主机端口映射到虚拟机 22 端口。
- 连接时使用 `127.0.0.1` 或 `localhost` 加映射端口。

---

## 二、Ubuntu 安装并启动 SSH

```bash
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
sudo systemctl status ssh
```

## 三、获取虚拟机 IP

配置端口转发时需要用到虚拟机 IP。

```bash
ip addr
```

## 四、配置端口转发

### 1. VMware Workstation

1. 打开 VMware，点击菜单栏：**虚拟机** → **设置** → **网络适配器**。
2. 选择NAT模式
3. 点击确定

## 五、从宿主机连接（推荐使用VScode）

使用vscode自带的远程资源管理器进行连接。

# Openclaw可能出现的问题

## 一、重新登陆openclaw提示token过期或忘记

- 最管用的解决办法（但是耗时最长）：终端输入：

```bash
sudo lsof -i :18789
```

用于查找18789被占用的进程

```bash
sudo kill -9 <PID>
```

终端该进程，然后重新运行安装脚本`./scripts/install-openclaw.sh`即可

## 二、Openclaw如何配置Deepseek

- 1. 进入到可视化界面以后，点击左侧**设置**
- 2. 选择**AI与代理**
- 3. 选择**models**
- 4. 下滑找到**Model Provider**
- 5. 必须填写内容：

  - 1. **Model Provider API Adapter** 设置为：**openai-completions**
  - 2. **Model Provider API Key** 设置为相应的API Key
  - 3. **Model Provider Base URL** 设置为相应的地址
  - 4. **Model Provider Model List** 点击 **Add**

    - 1. Api 设置为：**openai-completions**
    - 2. Base Url 填写对应的地址
    - 3. ID 设置为模型的名称
    - 4. Name 也设置为模型的名称
- 6. 点击**Save**以及**Update**
- 7. 创建新的对话，即可与deepseek对话

## 三、Openclaw如何安装skill

- 解决方法：
  1. 确定好skill位置
  2. 终端输入`openclaw skills install <文件夹路径>`

## 四、重新打开openclaw发现skill失效了

- 解决办法： 可以尝试在对话框内输入：`talk to agent`命令，让他加载默认的agent配置。

## 步骤一：配置SSH连接

由于ubutnu系统默认不安装ssh服务，因此，需要手动进行安装（如果比赛场景已经配置完成即可忽略此步骤）

## 步骤二：安装docker

此步骤询问AI，提示词如下：`我现在想要在ubuntu系统下，使用清华源安装docker，应该怎么做？`
随后根据AI的提示，进行操作即可。

## 步骤三：安装Python

此步骤依然询问AI，提示词如下：`我现在要在ubuntu系统中，安装python如何安装？`
随后根据AI回复，进行操作即可

## 步骤四：修改文件

修改module3/scripts里所有.sh文件，将`set -euo`修改为`set -eo`

## 步骤五：安装ROS2、Dify、Openclaw

在module3/scripts路径下打开三个不同的终端，分别运行

```bash
./install-dify.sh
./install-openclaw.sh
./install-ros2.sh
```

根据终端提示完成安装即可。

## 步骤六：配置Dify

1. 安装完成后，在浏览器打开:`127.0.0.1:3000/install`
2. 根据提示注册账号
3. 注册完成以后，点击右上角头像，安装`深度求索`插件
4. 待插件安装完成后，配置apikey。
5. 创建**对话助手**，在左边提示词中输入相应的提示词：“你是一个小龟教练”
6. 下滑，找到知识库部分，添加知识库
7. 选择创建知识库
8. 将module4/docs中的markdown文件导入进来
9. 选择经济模式，TOP K 设置为3-5之间的任意数字即可

## 步骤八：配置Openclaw桥连接

由于目前官方提供的`install-openclaw.sh`命令是通过安装openclaw的docker容器实现的，因此，我们需要进入到docker 容器中，使用openclaw，但是ros2的小乌龟在宿主机下，并不在docker中，所以openclaw无法调用小乌龟。

1. 使用`sudo docker ps`命令，查找到18789端口或者含有**oepnclaw**字样的容器ID，并记录下来
2. 通过`docker exec -it <容器ID> /bin/bash`的命令进入到openclaw的docker容器中。
3. 选择两种不同的方式进行openclaw配置

- 127.0.0.1:18789进行配置
- terminal进行配置

4. 两种不同的方式进行配置的流程如下


| 步骤 | terminal配置                                                                                                   | 127.0.0.1:18789                                               |
| ------ | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 1    | 终端输入`openclaw`命令启动openclaw                                                                             | 进入到可视化界面以后，点击左侧**设置**                        |
| 2    | `I understand this is personal-by-default and shared/multi-user use requires lock-down. Continue? `选择**yes** | 选择**AI与代理**                                              |
| 3    | `Setup mode`选择**QuickStart**                                                                                 | 选择**models**                                                |
| 4    | `Model/auth provider`选择**More/Deepseek**                                                                     | 下滑找到**Model Provider**                                    |
| 5    | `Install DeepSeek plugin?`选择**Download from npm**                                                            | 必须填写内容：                                                |
| 6    | `Enter DeepSeek API key`选择**sk-xxxxxx**                                                                      | **Model Provider API Adapter** 设置为：**openai-completions** |
| 7    | `Default model`选择**Keep current**                                                                            | **Model Provider API Key** 设置为相应的API Key                |
| 8    | 后面两项选择**skip for now**                                                                                   | **Model Provider Base URL** 设置为相应的地址                  |
| 9    | `Configure skills now? (recommended)`选择**yes**                                                               | **Model Provider Model List** 点击 **Add**                    |
| 10   | 后面选择**skip for now**或者**no**即可                                                                         | Api 设置为：**openai-completions**                            |
| 11   | `How do you want to hatch your agent?`选择**Hatch in Terminal**                                                | Base Url 填写对应的地址                                       |
| 12   | 完成配置                                                                                                       | ID 设置为模型的名称                                           |
| 13   |                                                                                                                | Name 也设置为模型的名称                                       |
| 14   |                                                                                                                | 点击**Save**以及**Update**                                    |
| 15   |                                                                                                                | 创建新的对话，即可与deepseek对话                              |

5. 配置完成openclaw以后，与AI进行对话（下面以terminal为例）
6. 与AI对话框内输入`talk to agent`切换到Agent模式
7. 将以下提示词发送给AI：`你现在在docker容器中，我的openclaw也在docker容器里面，我的ROS2小海龟是在宿主机中的，我现在希望通过openclaw可以去调用操作小海龟无法实现，我需要你通过搭建brige桥的方式，能够从docker容器里的openclaw操控宿主机的小海龟。`
8. 等到AI对话内容后（时间可能较长，此时可以操作别的内容），找到AI需要我们从宿主机中运行的命令，将其复制到宿主机的终端运行。

## 步骤九：openclaw安装skill

由于skill文件的bash和py文件以及skill.md文件都在宿主机中，并不存在于docker中，因此需要先将文件复制到docker容器里，才能安装openclaw skill。

1. 在宿主机环境下，输入`docker cp 宿主机文件路径 或容器ID:/app`（一般opencalw安装的路径在docker 容器的/app路径下）
2. 复制进来以后，通过`openclaw skills install <skill文件夹根目录>`
3. 安装完成后，即可通过openclaw操作ros2的小海龟了。

> 注意：在skill文件夹中的`drive_turtle.sh`文件仍然需要将`set -euo`修改为`set -eo`。
