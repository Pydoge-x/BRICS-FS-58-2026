# 数据增强

## 为什么要进行数据增强？

### 1. 防止模型过拟合：

    - 训练集样本数量有限，模型容易记忆训练数据的特定噪声或者背景。

### 2. 提升泛化能力和鲁棒性：

    - 模拟真实场景中光照变化、拍摄角度、人脸姿态偏移、遮挡等干扰情况，让模型在测试集和实际部署的时候表现得更加稳定。

## 常用的数据增强方法和类型有哪些？

### 1. 几何变换（Geometric Transformations）：

**核心原理**：改变图像中像素的空间坐标位置，但不改变像素本身的数值（RGB值）。主要用于模拟相机拍摄角度、距离和物体姿态的变化。

    - 随机翻转：
        -**水平翻转（Horizontal Flip）**：沿图像的垂直中轴线进行镜像对称。数学上，将原坐标$(x, y)$的像素映射到$(W-1-x, y)$，其中$W$为图像宽度。
        - **垂直翻转（Vertical Flip）**：沿水平中轴线上下颠倒。
    - 随机旋转：
        - 以图像中心或随机点为原点，将图像旋转指定范围内的角度。
    - 随机平移：
        - 将图像在水平轴和垂直轴方向上移动一定像素，超出边界部分通常进行裁剪或者边缘填充。用于模拟人脸在画面中不居中的情况。
    - 随机缩放与裁剪：
        - 随机截取图像的一个子区域，然后将其随访回目标尺寸，用于模拟拍摄距离变换。

### 2. 光度/色彩变换（Photometric/Color Transformations）：

**核心原理**：不改变像素的空间位置，只改变像素的数值大小。主要用于模拟不同环境光照条件、相机传感器差异以及图像压缩带来的影响。

    - 颜色抖动（Color Jitter）：
        - 随机改变图像的亮度、对比度、饱和度和色相。模拟现实中复杂的光照环境，迫使模型学习表情的几何纹理特征，而不是依赖特定的颜色或光照分布。
    - 随机灰度化（Random Grayscale）：
        - 以设定的概率将彩色图像转换为单通道灰度图。剥夺模型的颜色信息，强迫其依赖形状、边缘和纹理特征进行分类。
    - 高斯模糊与高斯噪声（Gaussian Blur / Gaussian Noise）：
        -**高斯模糊**：使用高斯核对图像进行卷积平滑，降低高频细节。
        - **高斯噪声**：向像素值中添加符合高斯分布的随机噪声。
        - **作用**：模拟低分辨率的摄像头、图像传输过程中的压缩伪影或传感器噪点，提高模型对低画质输入的鲁棒性。

### 3. 区域/高级混合增强（Region/Advanced Augmentations）：

**核心原理**：对图像的局部区域进行遮挡，或将多张图像进行混合。这是一种强正则化手段，用于防止模型过拟合，强迫模型关注全局特征。

    - 随即擦除（Random Erasing）/ Cutout：
        - 在图像中随机选择一个矩形区域，将其像素值全部填充为0、均值或随机噪声。模拟物体被遮挡的情况。
    - Mixup：
        - 将两张不同的图像$x_i$和$x_j$及其对应的独热编码标签$y_i$和$y_j$，按照随即比例$λ ∈ [0, 1]$(服从Beta分布)在输入空间和标签空间同时进行线性插值：
        $x_{new} = λx_i + (1-λ)x_j$，标签也做相同混合。
        - **作用**：在特征空间中生成训练集和测试集之间的插值样本，使得模型的决策边界更加平滑，防止模型对单一预测结果过度自信。
    - CutMix：
        - 将图像A的一个随机矩阵区域裁剪掉，用图像B的对应矩形区域进行填充替换。标签根据两个区域在图像中所占的面积比例进行混合。
        - **作用**：结合了Cutout（局部遮挡）和Mixup（标签混合）的优点，既保留了图像的大部分原始信息，又实现了强正则化，是目前图像分类任务中非常高校的增强策略。

## 使用torchvision的transforms进行代码片段实现：

```python

from torchvision import transforms
import torchvision.transforms.v2 as v2

# 随机水平翻转
transforms.RandomHorizontalFlip(p=0.5) # 参数 p = float， 表示触发水平翻转的概率是多少，取值范围为[0.0, 1.0]
# 随机旋转
transforms.RandomRotation(degrees=10) # degrees = float/tuple/list，表示在范围内进行随机选取旋转角度。
# 随机垂直翻转
transforms.RandomVerticalFlip(p=0.5) # 参数 p = float， 表示触发水平翻转的概率是多少，取值范围为[0.0, 1.0]
# 随机平移
transforms.RandomAffine(degrees=0, translate=(0.1, 0.2)) # degrees = 0为旋转角度为0， translate = tuple，表示水平和垂直方向上允许平移的最大比例（相对于图像总宽/高的比例）第一个为宽度最多10%，第二个为高度最多20%
# 随机缩放与裁剪
tansforms.RandomResizedCrop(size=224, scale=(0.08, 1.0)) # size = int/tuple 表示裁剪后期望输出的目标图像尺寸（后续传入神经网络的尺寸）， scale = tuple 表示裁剪面积占原图总面积的比例范围，(0.08, 1.0)表示随机截取原图8%到100&大小的区域

#  颜色抖动 
transforms.ColorJitter(brightness=0.4, contrast=0.5, saturation=(0.5, 1.5), hue=0.1) # bright,contrast,saturation,hue 分别表示为：亮度，对比度，饱和度，色相，前三个为抖动的幅度，色相为色相偏移量，分别传入float/tuple。前三个如果传入float系统就会在[max(0, 1-float), 1 + float]之间随机乘以一个系数，如果传入tuple则直接在tuple范围内取值。对于hue参数来说，传入的数必须是在[-0.5,0.5]之间，否则会导致颜色完全失真。
# 随机灰度化
transforms.RandomGrayscale(p=0.5) # p = float 表示转换为灰度的概率
# 高斯模糊
transforms.GaussianBlur(kernel_size=5, sigma=0.2) # kernel_size = int/tuple 表示高斯卷积核的大小，必须传入奇数。sigma 表示为高斯分布的标准差，控制模糊的弥散程度, 传入float/tuple，如果传入tuple则就在tuple范围内随机选一个sigma的值。

# 随机擦除/Cutout
transforms.RandErasing(p=0.5, scale=(0.02, 0.33), ratio=(0.3, 0.3), value="random")

# Mixup & CutMix
cutmix = v2.CutMix(num_classes=10, alpha=1.0, p=1.0)
mixup = v2.Mixup(num_classes=10, alpha=1.0, p=1.0)
```
